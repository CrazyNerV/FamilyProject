# Word Garden · 나의 영어 정원

사용자가 직접 영어 단어·숙어와 한글 뜻을 등록하고 연습하는 웹 프로토타입입니다.

## 실행

별도 빌드나 패키지 설치 없이 `dist/` 폴더를 정적 웹 서버로 제공하면 됩니다.

```sh
python -m http.server 5173 --directory dist
```

브라우저에서 http://localhost:5173 으로 접속합니다.

## 기능

- 단어·숙어 추가, 수정, 삭제 및 검색
- 브라우저 음성 합성을 이용한 영어 발음 재생
- 사전에서 중복 없이 무작위 최대 10문항 출제
- 한글 뜻 → 영어 전체 입력
- 한글 뜻과 일부 알파벳 → 빠진 알파벳만 입력
- 영어 → 한글 뜻 입력
- 즉시 채점, 결과 복습, 최근 100회 학습 기록
- 모바일 대응 화면

## 저장 및 채점

사전과 학습 기록은 현재 브라우저의 localStorage에 저장됩니다. 계정과 서버 동기화는 없습니다. 초기 체험용 표현 12개가 포함됩니다. 영어는 대소문자와 연속 공백을 정규화하며, 한글 뜻은 세미콜론으로 구분한 등록 정답 중 하나와 공백을 제외하고 일치하면 정답입니다. 의미가 비슷한 미등록 표현의 자동 판정은 지원하지 않습니다.

## 발음

Web Speech API의 speechSynthesis를 사용합니다. 별도 API 키는 필요하지 않습니다. 기기에 제공되는 영어 음성을 우선 사용하며, 음성과 품질은 브라우저·운영체제에 따라 달라집니다.

참고: https://developer.mozilla.org/en-US/docs/Web/API/Window/speechSynthesis

## 구성

- `dist/index.html`: 화면 구조
- `dist/style.css`: 반응형 디자인
- `dist/app.js`: 사전, 퀴즈, 저장, 발음

JavaScript 구문 검사는 통과했습니다. 현재 실행 환경의 로컬 브라우저 접속 제약으로 실제 화면과 음성 재생에 대한 브라우저 검증은 완료하지 못했습니다.
