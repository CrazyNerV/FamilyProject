02 · 버전 2에서 가져오기

  1. 위에서 백업 파일을 저장합니다.
  2. 버전 2에서 데이터를 받을 본인 계정으로 로그인합니다.
  3. ‘데이터 이관’에서 백업 파일을 선택하고 내용을 확인합니다.
  4. 계정과 공통 사전 반영 안내를 확인한 뒤 가져오기를 진행합니다.

같은 영어 표현은 기존 개인 사전의 뜻을 유지하고 건너뜁니다. 학습 기록은 합친 뒤 최근 100회만 보관합니다. 백업 파일에는 학습 데이터가 들어 있으니 본인이 보관해 주세요.
